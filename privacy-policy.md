## Для чего нужны данные

Расширение помогает уполномоченному пользователю проверить возможные дубли текущего заказа SalesRender. Проверка запускается по нажатию кнопки в карточке заказа.

## Какие данные обрабатываются

- Расширение определяет адрес текущей страницы SalesRender и идентификатор открытого заказа, чтобы выполнить запрос и убедиться, что пользователь остался на той же странице.
- Расширение считывает данные текущей сессии SalesRender из локального хранилища браузера и передаёт их серверу проверки для проверки доступа пользователя. Не вводите пароль SalesRender в расширение.
- Сервер использует идентификатор заказа и получает из SalesRender номер телефона, связанный с заказом, для поиска возможных дублей. Он проверяет сессию, роль и доступ к исходному заказу.
- Результат может включать идентификаторы найденных заказов, названия товаров, количество и статусы доставки. Результат отображается пользователю в карточке заказа. Согласно исходному коду номер телефона не включается в результат, возвращаемый расширению.
- Для безопасности и работоспособности могут обрабатываться технические данные запроса, в том числе IP-адрес, время выполнения, статус и идентификатор запроса. [Уточнить фактический состав данных сетевого уровня и журналов.]
